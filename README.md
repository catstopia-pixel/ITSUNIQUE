# It's Unique static website

## Consultation integration
- Kakao channel: http://pf.kakao.com/_RPMLG/chat
- Email recipient: hyojoon0310@gmail.com
- Static form backend: FormSubmit AJAX endpoint
- On first live submission, FormSubmit may send an activation email to the recipient. The recipient must confirm it once.
- Kakao Channel links do not provide a supported message-prefill parameter. The site copies the completed consultation message to the clipboard and then opens the channel chat.

## Local image
The Australia university service image is stored locally at `assets/images/australia-university.jpg` so it does not fail because of third-party hotlinking.
